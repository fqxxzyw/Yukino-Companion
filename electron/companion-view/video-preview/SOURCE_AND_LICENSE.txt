RENDER / CODEC
Blender 4.3.2 Cycles; fixed 640×640 orthographic camera; transparent film; RGBA PNG source frames; 8 samples, fixed random seed. Existing glTF single-sided outline behaviour is matched with an in-memory backfacing-transparent shader wrapper, as in upstream verified render. No new simulation, cloth, hair physics or collision correction. A constant +0.00067 model-unit floor wrapper offset follows the upstream V6 runtime metadata; periodic authored root motion is preserved, not re-normalized frame by frame.
FFmpeg libvpx-vp9, lossless codec mode, yuva420p, no audio. YUV 4:2:0 chroma conversion still changes colour samples relative to the RGBA renders. Alpha verified by explicit libvpx-vp9 decoding to RGBA, not solely a container tag.

LIMITATIONS
This is a bounded independent review preview, not a production-ready release or a Windows/Electron performance result. Known upstream armhole/chest sewn-layer contacts and front-hairlock/lapel contacts remain; there is no whole-model intersection-free guarantee or dynamic hair/cloth simulation. Turning, idle/walk cross-transitions, coordinated desktop translation, DPI/multimonitor behaviour, real-time rendering quality and long-run CPU/GPU/memory remain untested here. Standalone HTML preview does not implement the app state machine.
