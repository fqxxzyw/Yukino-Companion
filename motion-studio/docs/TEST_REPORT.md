# 本机验收

## 运行和操作

| 验收项 | 状态 | 本机结果 |
| --- | --- | --- |
| 类型检查、Lint、单元测试 | PASS | TypeScript 严格检查、ESLint 及 Node 单元测试通过，涵盖面板停靠、骨骼和眼睑绑定、表情覆盖、四元数插值、录制、片段时间、混合与格式校验。 |
| Windows 便携版 | PASS | 本机启动后真实渲染和服。确认原生标题栏的顶部内容偏移为 0，应用内的最小化、最大化、还原和关闭可用。通过桌面文件选择器创建并导入模型，独立播放器可播放动作包。 |
| 新建工程与导入 | PASS | 创建命名的无模型工程，导入真实骨骼 GLB 和含外置资源的 glTF。损坏文件、缺依赖或无可控通道时保留原模型。保存后按指纹重新定位了已改名的原模型。 |
| 工作区停靠 | PASS | 拖动中整块面板连同原 WebGL 画布移动。验证边缘停靠、面板交换、取消、分隔条调节、菜单重置和布局保存。 |
| 身体姿势与相机录制 | PASS | 选中骨骼节点不产生录制。拖动肩部节点改变真实上臂姿势，录制只包含对应骨骼。桌面版在录制中转视角和滚轮缩放，计时保持零且没有生成片段。 |
| GLB 导出和重新导入 | PASS | 校服动画导出后含骨骼旋转、根位移、表情权重、蒙皮和贴图。重新导入比对 0.5 秒位移、1.5 秒头部和微笑，数值一致。预览相机与其操作不进入输出。 |
| Companion 内嵌窗口 | PASS | Windows 免安装版从侧栏打开编辑器，重复点击复用窗口，验证文件菜单、身体姿势图及独立播放。关闭编辑器后主程序继续运行。 |
| 手动操控和录制 | PASS | 在和服模型上朝两个方向拖动头部滑杆，两次拖动之间松手等待 1.13 秒。录制窗口约 3.20 秒，导出的源片段约 0.87 秒，两次转头的末帧均保留。设置 2× 速度后保存。 |
| 工程恢复与独立播放 | PASS | 刷新后重新打开工程，并在新播放器窗口打开运行时包。三次读回的同帧旋转四元数一致，并确认播放器连续播放。 |
| 关键帧和时间线操作 | PASS | 浏览器实际写入两帧头部姿势、分割、撤销、跨轨拖动，验证锁轨禁止删除片段。 |
| 校服多轨叠加 | PASS | 同一帧有右臂挥动、歪头和真实微笑形态键。相同相机和模型下，右手高度从 1.073 提升到 1.627 个预览单位。 |
| 原始资源完整性 | PASS | `npm run verify:assets` 复核 37 个源文件，包含全部 17 个 GLB。模型从本机文件只读加载。 |

浏览器回归命令为 `npm run test:browser`，默认连接 `http://127.0.0.1:5197/`。用 `npm run test:browser -- http://127.0.0.1:5198` 可指定另一个本地服务地址。要复录视频，可先安装 Playwright 的 FFmpeg，再设置 `MOTION_QA_VIDEO=1`。打包后可用 `npm run test:desktop` 复验便携版窗口与重启流程。证据在本机的 `artifacts/browser-qa/` 和 `artifacts/desktop-qa/`，包含用户角色外观，仅在本机保留。

## 和服交付样例

浏览器验证了两份原样例的双眼闭合、左眼独立睁开和双眼复位。VRM 两次离散操作之间停顿 0.7 秒，保存的动作只有左右眼两个通道，时长 0.067 秒。GLB 播放内嵌 `Blink` 时，手调的微笑权重保持 0.12；`SmallStepWalk` 驱动实际根节点，`GentleGreeting` 的两项裙摆修正权重均保持 1。GLB 的四肢已可在人体图选中。两份文件也在隐藏窗口中通过了 Windows 便携版的导入与闭眼验证。

复验时在 `MOTION_KIMONO_DIR` 指定原样例所在目录，启动生产构建后运行 `node scripts/kimono-qa.mjs`，也可用同一变量运行 `npm run test:desktop`。样例和截图仅保留在本机。

## 部分完成与待验证

- **眨眼、闭眼、左右 Wink**。动作曲线和冲突规则已通过单元测试。原内置模型缺少眼睑形态，新交付的本地和服 GLB 和 VRM 有实际闭眼通道。和服 VRM 1.0 的浏览器加载记录确认右眼闭合权重从 0 变为 1，恢复参考姿势后回到 0。
- **挥手和走路自然度：PARTIAL**。程序化挥手已验证能驱动真实关节。校服走路评审版的原始 `Walk_Slow_Loop` 在生产版浏览器中实际驱动了脚踝。第 12 帧的左脚踝纵深由 0.020 移到 −0.242 个预览单位。脚底接触、滑步、衣物穿模和不同衣装下的动作质量仍待逐项验收。
- **口型：PARTIAL**。已接入真实权重和手动关键帧。音频轨、自动音素对齐和语音驱动待实现。
- **头发与衣物物理：PARTIAL**。和服 VRM 1.0 的浏览器加载记录中，转头后 10 个弹簧关节均产生姿态变化，碰撞体为 0。交付和服 GLB 的裙摆是烘焙效果。头发碰撞和实时布料求解未验收。
- **导出范围**。工程 JSON 可继续编辑，动作 JSON 可由独立播放器读取，GLB 可烘焙运动学动画。VRM 保留原文件并导出动作 JSON。音频、物理模拟结果和工作区信息不写入 GLB。
- **渲染性能：NOT TESTED**。当前验证为 Windows Chrome 与 Electron 的功能回归。不同显卡、长时间运行和大型时间线待测。
