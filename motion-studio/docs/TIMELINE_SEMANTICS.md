# 时间线语义

工程帧率为 24、30 或 60 FPS。片段起点 `start` 与工程保存的 `playhead` 使用整数帧。源裁剪、模块关键帧、拉伸和淡入淡出用秒。帧率变更时按原起点的秒数换算到新的最近整数帧。拖动与点击播放头按帧对齐，启用「吸附」后，拖动片段或右边缘也会寻找附近的播放头和片段边界。

| 参数 | 含义 |
| --- | --- |
| `sourceIn`、`sourceOut` | 模块源时间中的有效区间 |
| `speed` | 未设拉伸时，每经过一秒时间线播放多少秒源动作 |
| `loops` | 将有效源区间重复的次数 |
| `stretch` | 可选的总时间线时长。设置后，将完整源序列按比例铺到指定总时长 |
| `blendIn`、`blendOut` | 片段边缘的权重过渡时长 |
| `window` | 分割后保留的原片段时间比例，以 `0–1` 的 `from`、`to` 表示 |

自然总时长是 `(sourceOut - sourceIn) / speed × loops`。例如原片段四秒，源入点一秒、源出点三秒，`speed = 2`、`loops = 3`，自然总时长为三秒。若设 `stretch = 6`，相同的源区间与循环次数均匀分布在六秒上。拖动右缘修改拉伸，源裁剪在片段属性中修改。分割过的片段可见时长为完整时长乘以窗口比例 `to - from`。

对给定工程时间，先扣除片段起点，再根据 `window` 还原到分割前的进度，从原时间区间映射到完整源序列。完整序列用有效源长度折回到当前循环，再加源入点，得到模块采样的源秒数。播放时段含片段起点，抵达结束时间即释放通道。分割在播放头所在的整数帧进行，两个子片段保留原相位和原淡入淡出包络。

时间线上可以拖动单片段跨轨，或选中多个片段一起水平移动。锁定轨道可参与播放，轨道上的片段禁止移动、裁剪和分割。复制后粘贴以播放头为起点，保留多个片段之间的相对时间。静音轨道不参与求值，有独奏时仅求值未静音的独奏轨道。
