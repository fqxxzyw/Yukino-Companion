# 可编辑工程格式

工作台保存的 `.motionproject.json` 是 UTF-8 JSON，旧的 `.yukinomotion` 工程也可打开。顶层 `format` 为 `yukino-motion-project`，其余字段来自 `Project`。`readProject` / `writeProject` 是读取和写入入口。编辑器打开工程时恢复轨道、片段、动作模块与播放头。

| 字段 | 内容 |
| --- | --- |
| `version` | 当前工程数据版本 `1` |
| `id`、`name` | 工程标识和可编辑名称 |
| `modelId` | 内置模型 ID、本地导入模型的 `local:` ID，或代表暂未选模型的 `none` |
| `fps`、`playhead` | 帧率和保存时的播放头帧号 |
| `tracks` | 按显示顺序排列的轨道与片段 |
| `modules` | 工程保存的动作定义数组，内置过程模块也可按 ID 引用 |
| `asset` | 模型名称、可用时的相对路径和 SHA-256 |
| `mappings` | 按模型 ID 保存的语义骨骼和形态键映射 |

轨道含 `id`、`name`、`region`、`muted`、`solo`、`locked`、`clips`。每个片段用 `moduleId` 引用模块，保存开始帧、源裁剪、速度、循环、拉伸、权重、混合模式、淡入淡出与参数覆盖。相同模块可被多个片段使用，调整某片段的播放速度只影响该片段。编辑共享模块的关键帧通常会影响全部引用。若有锁定轨道引用同一模块，编辑器会为当前片段复制模块后再应用编辑。

工程通过引用关联原始资源。浏览器重新打开工程时，可从本地服务器重新读取内置资源。对于外部导入的模型，应保留原文件及其依赖，并按编辑器提示重新定位。原资源与依赖内容相同即可恢复关联。文件指纹不一致时重新选择正确资源。编辑历史和临时手动调整存在编辑会话中，提交为关键帧或录制片段后才随工程保存。

加载时校验格式与版本、帧率、ID 唯一性、片段对模块的引用、时间和裁剪范围、关键帧顺序、插值模式以及数据维数。旋转值应为单位四元数。未知的过程动作和超出范围的表情权重会使文件校验失败。
