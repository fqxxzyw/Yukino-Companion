# 通道遮罩与混合

时间线以 `rotation`、`translation`、`expression` 和通道语义 ID 为基本单位。每一帧先创建空姿势缓冲，再从活跃片段收集各通道值。轨道的 `region` 决定哪些属性可以进入缓冲。「全通道」接受所有通道，「身体」接受除 `root` 外的骨骼旋转和位移。头颈、左臂、右臂、下半身、眼部、面部和口型轨道可分别承载对应的控制。

有效权重为片段权重乘以两个淡化系数中的较小值。轨道与轨道内片段顺序用于稳定处理相同优先级的输入。更高优先级在之后应用。

| 混合模式 | 同一属性的计算 |
| --- | --- |
| 覆盖 `override` | 在前面算出的结果与片段目标之间插值。 |
| 增量 `additive` | 位移加上加权向量，旋转乘以从单位四元数向目标球面插值得到的加权旋转。普通表情加入加权值，眼睑取最大值。 |
| 优先 `priority` | 先把这一属性恢复为单位旋转、零位移或零权重，再按片段有效权重趋近目标。其他属性保留。 |

旋转以单位四元数混合，表情权重限制在 `0–1`。

同一时间有多个活跃片段写入同一个通道时，右侧属性面板可以查看重叠通道。可调整轨道区域、淡入淡出、权重、混合模式与优先级。可让走路在下半身轨道、挥手在手臂轨道、歪头在头颈轨道，分开各自作用的属性。添加原地走路时，如需保留步态的周期性根节点位移，应使用允许 `root` 的轨道范围。

表情混合按真实形态键语义分离。例如微笑和张嘴各有独立通道时，可以在不同轨道控制。写入双眼闭合通道会清除已有的单眼值，写入单眼值会清除已有的双眼值。闭眼保持片段的默认优先级为 `10`。冲突报告会将双眼闭合拆成左右两眼，以便与单眼片段比较。双眼与单眼的映射取决于实际 GLB。手动操控仅在编辑器预览层按通道覆盖当前姿势，录制或写入关键帧后可进入工程与导出。
