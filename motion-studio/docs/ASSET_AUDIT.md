# 本地模型资源审计

审计读取了主项目的 README、依赖清单、角色注册表、GLB 加载与八权重蒙皮实现、衣物配置、行走资源元数据和对应测试。检查以 `public/characters` 下的输入文件为准。`build` 和 `dist` 中的重复构建副本不计入源资源。

本次审计记录了 37 个本地文件的路径、大小和 SHA-256，包括 17 个 GLB、7 张 PNG 缩略图，以及源文件索引、动作元数据、授权说明和 7 份衣物配置。17 个 GLB 的字节数和 SHA-256 均与 `resources/character-models.json` 一致。工作树内没有 `resources/character-source/sources.json` 列出的 `.glb.gz` 压缩源，表中模型的本地 GLB 均可直接读取。另有代码引用的 `review-assets/Yukino06_BilateralBlink_REVIEW.glb`，本地文件缺失。详见 [完整资源清单](asset-manifest.json)。

在编辑器目录运行以下命令可重新核对原始资源。校验读取父目录中的资源，结果与编辑器内保留的基线对照，退出码为 `0` 表示 37 个文件和提取数据全部一致。

```powershell
node scripts/audit-assets.mjs --verify
```

## GLB 内容实读

所有输入文件均为 GLB 容器 2、glTF 2.0，导出器为 Khronos glTF Blender I/O v4.3.47。每个 GLB 都有一套 skin，含 55 个 joints 和逆绑定矩阵。层级主要由 Root、髋、脊柱、胸、头颈、双臂、双腿、手指与两根眼部辅助关节组成。完整节点名称与直接父节点可在清单的 `rigHierarchies` 中按 `hierarchyId` 查询。清单还记录根骨局部参考姿态、各模型完整参考姿态与逆绑定的摘要。01–07 的参考姿态及逆绑定摘要各不相同，同名骨骼在不同服装上使用各自的局部轴与参考变换。

原配置记载场景坐标为 +Y 朝上、+Z 朝前，角色自身的左侧为 +X。数值单位按 glTF 米。下表尺寸来自基础网格的位置访问器，是网格局部坐标包围盒。07 的行走元数据另行记录了动画作用下的地面高度范围。

原贴图均以 JPEG 或 PNG 内嵌，无外部缓冲区或贴图依赖。07 系列附带 `KHR_materials_unlit` 材质及轮廓网格。模型 01 的全部 21 个 primitive 含 `JOINTS_1` 与 `WEIGHTS_1`，主项目将基础版标为 HOLD。完整预览需要保留这四个附加权重。其余模型使用单组骨骼权重。

01–06 共有 `Idle_Breathe`、`Listen_Attentive`、`Look_Left`、`Look_Right`、`Nod_Subtle`、`Think_Downcast`，均针对 55 根关节分别记录旋转、平移、缩放。07 基础版另含 `Explain_Small` 和 `Greet_Reserved`。清单列出各版本实际动画名称、源时长及各属性通道数。

07 的基础版、微动作 13、行走 14 和语音微动作 19 版本在基础几何、蒙皮属性、材质、图片、骨骼层级、参考姿态、逆绑定矩阵和表情数据的摘要均一致。行走与语音微动作版本都含 `Walk_Slow_Loop`。本地评审资料将其记为基于 CMU 07_04 的原地慢走，`Root` 保留周期性位移，循环的净位移为零。动作应保留这些局部位移。接触、滑步和衣物外观仍需以实际播放器测试为准。

## 表情与物理限制

- 01–06 基础版面部只有 `mouth_open_small`。07 的 `MouthOpen` 和 `viseme_A` 在主项目资源合同中按替代通道处理，逐帧编辑时应避免叠加两者。07 的口型通道分别定义于主体与轮廓网格。
- 所有本地 GLB 都含 `J_Adj_L_FaceEye` 和 `J_Adj_R_FaceEye`。扫描每个基础版和 07 的三个动作评审版的 `JOINTS` / `WEIGHTS` 数据，两根关节均没有非零顶点权重。找不到眼睑骨骼或眨眼 Morph Target，无法以现有资源做真正的眨眼、闭眼、Wink 或独立转眼。
- 17 个 GLB 均未发现独立的头发或衣物骨骼、弹簧扩展、碰撞配置。7 套 `GarmentNormal` 变体与对应基础版共享骨架、几何和蒙皮，另含需由对应衣物配置驱动的局部姿态修正 Morph Target。它们是特定姿势区间内的网格修正。当前资产审计没有进行衣物、头发或碰撞仿真。
- 需求中的三套未确认服装的加载、重定向和外观验收处于 `BLOCKED`。已找到文件的逐项编辑器与播放器验收以测试报告为准。
