# 编辑器与播放器架构

动作编辑器共享同一套 Vite 构建，在浏览器、Windows 便携版和 Yukino Companion 的独立窗口运行。便携版通过只绑定本机的服务器读取资源。Companion 从打包的 `dist/motion-editor` 启动隔离窗口，模型使用已打包的角色资源。两个桌面入口都提供独立播放器。工程和动作 JSON 保留模型引用，标准 GLB 导出则写入模型和烘焙后的动画。

```text
本地 GLB / glTF → 格式与指纹校验 → ModelRig → 语义通道与参考姿态
                                               ↓
工程轨道 → 绝对时间求值 → Pose → ModelRig.apply → WebGL 绘制
              ↑                         ↑
         复用模块库                 编辑器手动操控层
```

- `src/motion/` 定义动作数据和纯求值逻辑。`Pose` 是稀疏通道缓冲，按语义 ID 保存旋转、位移、表情权重。项目和时间输入相同则求值一致，播放、拖动和跳转共用这条路径。
- `src/model-rig.ts` 读取骨架与形态键，建立语义 ID 和原始节点的映射，将 GLB 内置动作转换为关键帧模块。`apply` 每次先恢复参考状态，再写入当前缓冲。旋转和位移以模型参考坐标转换；表情写入绑定的真实形态键。
- `src/viewport.ts` 负责校验、场景、骨架辅助、相机和资源生命周期。模型切换以新请求为准，迟到的加载结果释放各自的资源。预览按交互、模型变化和播放帧申请绘制。
- `src/main.tsx` 管理工程、编辑历史、手动关节输入和录制。手动输入按属性覆盖当前时间线姿势。录制结束生成独立的关键帧模块，可继续编辑和复用。
- `src/session.tsx` 提供视窗、绝对播放时间和文件下载。编辑器与播放器共用视窗和求值器，分别管理各自的文件和操作界面。

各层边界和通道处理方式详见 [模型适配](MODEL_ADAPTER_GUIDE.md)、[混合规则](BLENDING_RULES.md) 和 [物理集成](PHYSICS_INTEGRATION.md)。
