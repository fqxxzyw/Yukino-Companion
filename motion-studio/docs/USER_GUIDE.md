# 制作一段动作

在 Yukino Companion 侧栏点击「动作编辑器」，或在 Windows 运行便携版 `Motion Editor.exe`。工作台目录的 `start.cmd` 可启动浏览器版，默认地址是 `http://127.0.0.1:5197/`。默认布局中间显示当前角色，下方是时间线，右侧是属性。命令行启动方式见 [README](../README.md)。

## 调整工作区

- 拖住标题，整块面板会随鼠标移动。放在另一面板上可交换位置，放在工作区外缘可停靠成整行或整列。按 Esc 或拖出工作区可取消。
- 拖动面板之间的分隔条调整宽高。也可以用 Tab 聚焦分隔条，再按方向键调整。
- 点击标题右侧的把手，可从菜单选停靠位置或要交换的面板。用「视图 → 恢复默认布局」可以回到初始位置。调整后的布局会记在本机。

## 手动操控与录制

三维视窗下方可选择室内摄影棚、暖光、冷光和室外晴天、阴天、夕阳。灯光只影响当前预览，不会录进动作。人体图跟随模型骨骼和主视窗方向：拖动关节点调整姿势，拖动图中空白处旋转观察视角。

人体图中选择「手脚 IK」，拖动手腕或脚踝可联动相应的上臂与前臂，或大腿与小腿。拖不到的位置会限制在肢体长度内；选「关节旋转」可逐个调整关节。录制时，实际变化的关节会写入动作，旋转观察视角不会录入。若模型缺少完整的上下肢骨骼，或正在显示参考姿态，IK 会提示不可用。

新录制的通用动作会保存模型的上臂和大腿参考方向，切换到其他已映射模型时按目标参考姿势调整；模型自带的专属动作仍需使用原模型。旧工程没有参考方向时按原样播放。模型比例、衣物及足部接触仍需要人工检查和调整。

从 Companion 打开的编辑器会跟随 Companion 的主题颜色、深浅色与减少动态效果设置。独立运行编辑器时可继续使用右上角的主题切换按钮。

1. 点击顶部「新建」，填写名称并选择起始模型。可选现有角色、导入本地模型，或暂时创建无模型工程。也可在视窗上方用「导入模型」换用本地 VRM、GLB 或 glTF。glTF 使用外置资源时，一并选择 `.bin` 和贴图或其文件夹。等角色加载完成。
2. 在右侧「身体姿势」图上点选头部、肩、手腕、膝或其他已映射关节。横拖关节绕 Z 轴转动，竖拖绕 X 轴转动。头颈、胸廓、骨盆、手掌与脚的轮廓会随关节姿势更新，选中的节点会显示名称。也可从左侧列表或三维视窗的「骨架」选关节，再用右侧滑杆细调 X、Y、Z。位移输入以角色参考高度的百分比显示。
3. 把播放头放到想插入动作的位置，点「开始录制」。拖动滑杆调节关节或表情，可以松手后切换关节继续录制。片段只累计实际操控的时长，开始前、松手间隔和停止前的等待会自动跳过。单击滑杆、按方向键或输入数值的单次变化各占一帧。
4. 点「停止录制」。编辑器会把有手动输入的通道写入一个关键帧动作，并在时间线选中新片段。点播放或拖动播放头检查效果。
5. 在右侧「片段」调整「播放速度」。例如 `0.5×` 会把自然播放时长加倍，`2×` 会减半。想保留源速度设置并直接指定总时长，可输入「拉伸时长」或拖片段右缘。

## 控制表情和眼睛

- 在右侧切换到「表情」。对于有眼睑通道的模型，可分别按「双眼」「左眼」「右眼」对应的「睁开」和「闭上」。部分闭合可在「眼部细调」中拖动滑杆。缺失的闭合通道会在对应位置提示。
- 在「面部表情」「口型与嘴部」等分组拖动权重，或按名称搜索通道。拖动可以录制连续变化，睁眼和闭眼按钮可以录制单帧操作。暂停时可选中通道后点「写入关键帧」，手动预览后可点「交还时间线」。
- 内置原和服只有张嘴通道。新交付的本地和服 GLB 与 VRM 都有双眼和左右眼闭合通道，需手动导入。校服可试微笑、张嘴与 A/I/U/E/O/MBP 口型。原始形态键和模型正式定义的表情可能不同，详见 [模型适配](MODEL_ADAPTER_GUIDE.md)。

## 关键帧与片段组合

时间线上的「吸附」开启时，拖动片段或调整末端可对齐播放头及其他片段的起止位置，蓝色参考线显示对齐点。用缩放滑杆调整时间尺度，刻度会铺满可见区域。

- 做精确姿势时，先暂停播放，调整关节，点「写入关键帧」。新建的关键帧片段可在源时间内追加更多帧。选中该片段，把播放头移到片段内部，回到「操控」调到下一姿势，再写一次关键帧。
- 在「片段 → 关键帧」展开对应关节，编辑源时间和插值，或把一帧复制到当前播放头。普通关键帧编辑会更新共享模块。若锁定轨道引用同一模块，当前片段会使用自己的副本。
- 点左侧「动作模块」可在当前播放头把动作插入相应身体区域的轨道，也可以拖到指定轨道和起点。将歪头和右手挥动放到各自身体区域的轨道，可以同时播放。
- 交付和服 GLB 自带 `SmallStepWalk`（小步走）、`GentleGreeting`（轻柔问候）和 `Blink`（眨眼）。走路与问候保留原有裙摆烘焙效果，在重叠区间按互斥顺序播放。交付 VRM 没有内置动作片段，可用工作台动作、手动控制或录制制作新片段。
- 用 `Ctrl` 或 `Shift` 点击多个片段可以一起水平移动。`Ctrl+C` 和 `Ctrl+V` 复制及粘贴到播放头，`Delete` 删除，`Ctrl+Z` 撤销，`Ctrl+Shift+Z` 或 `Ctrl+Y` 重做。
- 想检查初始姿态，点视窗的「参考姿态」按钮。要在时间线上找准某一帧，可缩放时间线，再使用刻度或轨道空白区域拖动播放头。

## 保存与独立回放

「文件 → 保存工程 JSON」下载 `.motionproject.json`。用「打开工程」重新编辑，旧版 `.yukinomotion` 也可以打开。自定义模型换位置后，用「定位本地模型」选回原文件及其依赖。要改用新角色，请选择「导入模型」。

「导出动作包」下载 `.motion.json`。在视窗上方打开「独立播放器」，点「打开动作包」选择刚导出的文件。等角色准备完毕后点击播放，或拖动进度条观察关键时间点。播放器载入自定义模型时也需要本地原文件。

对于 GLB 或 glTF 角色，选择「文件 → 导出带动画的 GLB」，按当前工程帧率把时间线烘焙进标准三维文件。可在工作台重新导入该文件，再从动作模块库选择其中的烘焙动作。对于 VRM 角色，请保留原 `.vrm` 并导出动作 JSON。转动视角、缩放和相机平移只用于观察，均不会进入录制或导出的动画。
