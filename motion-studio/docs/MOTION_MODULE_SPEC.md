# 动作模块规范

`MotionModule` 由 `id`、`name`、`duration`、`region` 和 `kind` 标识，可携带 `version`、说明与 `modelId`。`duration` 用秒。`region` 用于分类和默认轨道，片段最终作用范围由所在轨道的遮罩决定。带 `modelId` 的内置素材与原模型关联。

| 模块类型 | 输入 | 使用方式 |
| --- | --- | --- |
| `procedural` | 过程名、参数定义、片段参数覆盖值 | `sampleModule` 取源时间与参数，生成语义通道值。受参数范围约束。 |
| `keyframes` | 有序时间与值组成的通道数组 | 用户录制、手工关键帧和 GLB 内置动作共用此结构。 |

三个通道分别为 `rotation`、`translation` 和 `expression`。`key` 是语义 ID，例如 `head`、`rightLowerArm` 或 `smile`。旋转值为 `[x, y, z, w]` 四元数，位移为 `[x, y, z]` 向量，表情为 `0–1` 标量。时间在模块自身的源时间内，以秒表示。关键帧的 `interpolation` 控制从这一帧到下一帧的过渡，`linear` 为默认值，`smooth` 先对区间进度做平滑，`hold` 保持当前值到下一帧。旋转插值沿四元数球面进行。

GLB 内置动作在加载时转换为同一种关键帧模块。可映射的骨骼旋转、骨骼位移与 Morph 权重进入缓冲。未发生变化的参考旋转与位移可省略。动画缩放、三次样条和独立网格同名形态权重的转换限制显示在模型能力中。

录制器按项目帧率对滑杆或身体图关节每次拖动中的实际变化取样。从这次拖动的首次变化到末次变化保留原节奏，下一次拖动紧接上一段的末帧。单次离散变化占一帧。结束时压缩连续相同值，保留变化边界，只把有实际变化的旋转、位移或表情通道写成模块。点选关节或移动预览相机不会产生动作关键帧。

增加程序动作时，应在 `src/motion/types.ts` 增加过程标识，在 `src/motion/modules.ts` 声明参数、长度和适用区域并实现绝对源时间函数。输出复用现有语义通道。`moduleRequirements` 读取模块需要的通道，编辑器根据实际角色适配器提示缺失的映射。当前挥手为程序化制作起点，幅度、节奏、抬臂和屈肘可改，最终视觉质量由实际服装预览决定。
