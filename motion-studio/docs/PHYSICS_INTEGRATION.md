# 物理与姿态边界

当前运行路径对原始 GLB 的骨骼、蒙皮权重、材质、贴图与形态键做只读加载。`ModelRig` 按绝对时间恢复模型参考状态，应用运动学姿势和形态权重，再交给 Three.js 蒙皮绘制。时间跳转与换模直接重新求值。模型能力面板会标出弹簧和碰撞求解不可用。

已登记的本地基础 GLB 未发现弹簧骨、布料或碰撞求解数据。单独的 `GarmentNormal` 变体提供有配置范围的姿势修正形态。主项目为这些形态另外提供驱动配置。当前工作台不会自动运行这套衣物驱动。`Walk_Slow_Loop` 包含原地行走时的根骨周期性位移，这部分作为动作通道处理。

日后接入物理时，输入应为已经应用的运动学姿势，输出只写模拟器拥有的骨骼或形态。时间跳转、重新播放或换模应在模拟层独立复位，或者从固定步长缓存恢复。当前导出仅覆盖运动学通道，导入方若有物理模块应自行维护模拟状态。现有文件完整性和物理资源检查见 [资源审计](ASSET_AUDIT.md)。
