MODELS & API

模型与 API

想离线，就在电脑上跑；想用熟悉的服务，就接在线 API。三项可以分开选。

离线运行装好后，断网也能用
在线 API接自己常用的服务

01 对话

离线运行
雪乃本地模型

基于 Qwen2.5，也能连接本机的 Ollama 或 LM Studio。

在线 API
用你熟悉的模型

OpenAI、DeepSeek、通义千问、Kimi、火山方舟等，也能接自定义兼容接口。

02 翻译

离线运行
混元 Hy-MT2

下载模型后，可以在电脑上把中文译成日语。

在线 API
用同一个，也能另选

翻译可以沿用对话模型，也可以单独选一个兼容的文本模型。

03 语音

离线运行
GPT-SoVITS

本机合成日语语音，也可以导入自己的音色。

在线 API
阿里云百炼

支持语音合成和麦克风实时转写，两项可以分别配置。

其他对话服务腾讯混元、智谱 GLM、硅基流动、Google Gemini（兼容）、Azure OpenAI、百度智能云千帆、讯飞星火、MiniMax、阶跃星辰、零一万物、商汤日日新、Mistral AI、Groq、Together AI、OpenRouter、xAI Grok
