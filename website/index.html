MODELS & API

模型与 API

对话、翻译、视觉、语音识别和语音合成分别路由。API 凭据保存在本机安全存储，不进入网页。

对话本地 · oregairu-small / 自定义 API
翻译本地 Hy-MT2 / 独立翻译配置
语音识别实时 ASR · 按住或自动断句
语音合成GPT-SoVITS · 云端语音可选
视觉屏幕 / 摄像头 · 预览后授权
对话翻译语音识别语音合成视觉本地模型

为每个任务选择不同的服务与模型。密钥只保存在本机；网页和安装包不会包含服务端密钥。

MEMORY & VISION

记忆与视觉

个人记忆可选择是否用于对话。屏幕或摄像头截图先预览，再授权发送给视觉模型。

MEMORY个人记忆

希望她记住的事，保存在本机；每条记忆可以单独启用。

视觉

先预览截图，再授权发送。需要单独配置支持图片的模型。

MAKE IT YOURS

不止雪之下雪乃

创建自己的角色、导入自己的记忆、调整模型与动作。所有内容按角色独立保存。

01

创建角色

名字、外观、性格和说话方式都可以重新设定。新角色拥有独立的聊天与进度。

02

导入记忆

记忆导入
03

模型与动作

模型动作编辑器

ACCOUNT

账号与同步

不登录也能使用。登录后，登录天数、好感度和永久服装由服务器确认；网页账号中心可查看设备和修改密码。

游客

好感度、陪伴日期和本地皮肤保存在本机，重启不丢失。

已登录

每日确认按上海自然日计一次；好感度只接受服务端审核的互动。

离线

已确认的皮肤和本地功能继续可用；云操作恢复联网后同步。
