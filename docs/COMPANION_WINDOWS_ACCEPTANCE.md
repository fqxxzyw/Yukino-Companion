# 桌宠、桌面 3D 气泡与设置窗口验收

日期：2026-10-31。只处理桌面窗口及设置交互，不恢复暂停的场景开发，不修草稿模型材质，不改变模型摘要、01 HOLD 或使用日期 / 好感解锁规则。

## 本次修复

1. **3D 最小缩放正文被压扁**：原生窗口为 320 × 330 DIP 时，正文实际只剩 14px，而一行文字需要 23.1px。提高独立气泡保留区的最小高度，正文和操作按钮仍分开布局，不改变文字字号。
2. **3D 透明度影响整个交互界面**：原来给根节点设置 opacity，气泡、工具栏和输入条会一起变淡。改为只给模型画布 / 无模型时的角色占位层设置透明度；菜单和文字控件保持清晰。
3. **桌宠贴边后气泡落到屏幕外**：原来只保证身体在屏内。可见回复存在时，拖动、行走及偏好重排使用完整窗口的安全边界；回复在贴边后才到达时，纠正位置并保存。拖动中收到回复不立即挪动窗口，等释放再约束。隐藏 / 清除气泡后仍保留原有身体边界拖动，不把完整窗口边界写成永久身体范围。
4. **同时显示的默认气泡互相遮挡**：默认间距原来固定为 `230 × scale`，没有考虑窗口最小宽度。改用桌宠的实际窗口宽度加 12 DIP 放置另一个默认窗口。已有用户保存位置不被强制重新排版；不能承诺用户主动拖到一起后也自动避让。
