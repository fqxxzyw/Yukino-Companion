# 2026-10-30 用户反馈修复

此批在接续分支实施；现有七套人物资源保留，未修改独立任务中的 108 项新动作。安装器继续先发布测试版，再在 Windows 上验证。

- 人物展示：玻璃边框内外角采用一致的内缩关系，去掉底部左右箭头，动作入口移到边框外；保留拖动面板改变停靠位置。
- 联系人：侧边栏列出全部角色，角色下可展开自己的历史对话；跨角色选择历史时同时切换角色，搜索同时覆盖角色与对话，保留原记录和删除确认。
- 3D 桌面人物：回复放在固定高度的顶部栏，内容限制宽度和行数；默认中文、尊重现有语言选择。窗口移动时仅在原生窗口尺寸发生漂移时恢复既定宽高；真实多显示器及不同缩放比例仍需实机确认。
- 视觉陪伴：移除默认 File/Edit/View/Window 菜单，使用与应用接近的无边框面板和可拖动标题栏；未改变视觉采集、发送确认和关闭撤销权限的机制。
- 下载：使用随包提供的 aria2，每个支持范围请求的分卷最多 8 个连接、最小分段 1 MiB；不同分卷和独立文件并行，最多 64 个分卷任务共享预算。运行环境、对话、翻译和桌宠资源并行，声音在运行环境准备好后并行准备公共组件及音色。保留资源哈希、分卷顺序合并、续传、取消和安全回退；实际连接数和速度受服务器及网络限制。
- 后台声音：选中音色的后台安装由主进程完成并保存，后台变更不会覆盖用户之后选取的本地文件。停止聊天只停止翻译请求，不取消翻译资源安装。声音公共组件和权重的并行结果通过串行事务合并设置。
- 语音：默认参考文本留空；已有的 v1/v2 引擎允许空文本，v3/v4/v5 要求文本。参考音频仍为 GPT-SoVITS 必需输入；随包小型参考音频经过校验后可供使用，用户可选本地 .ckpt、.pth 和参考音频，首次朗读时自动加载。未实测不同权重组合的音质或兼容性。
- GPU：运行环境未安装时也独立检测 NVIDIA 硬件；如果目录只提供 CPU 环境，明确提示 CUDA 下载暂不可用，不把“提供 CPU 安装包”说成已安装或已使用 CPU。硬件检测不等于 CUDA 驱动、运行时与实际推理均可用。

补充反馈：

- 复制当前显示的回复使用受主窗口约束的 Electron 系统剪贴板接口，不再依赖已禁止权限的浏览器剪贴板。
- 一键配置的功能开关在检查和现有下载期间都可修改；现有下载按原有选择继续，完成后重新检查新选择。
- 设置界面分别列出 GPT `.ckpt` 与 SoVITS `.pth`：每项都可以下载指定公开文件或选择本机文件，也能并行下载整组。分开下载时只应用对应路径；后台下载完成不会覆盖之后改选的同一文件。
- 内置短参考声音自动配置，默认参考文本留空；自定义参考声音退到高级选项。现有桌宠语音压缩包和原项目只提供无情绪标签的文件名及随机播放，尚无可核验的平和、愤怒等分类；不能声称按回复情绪自动切换参考声音，后续需要听音标注及实际合成验收。
- 公开运行环境清单当前仍只有 CPU；没有发布或实测 CUDA 包，检测到 NVIDIA 时明确提示这一限制，不能声称已经完成 GPU 推理环境。
- 保留用户提供的中、英文技能原文；内置雪乃启用时根据对话语言采用相应核心节选，并在人物关系、猫与阅读等具体话题补充匹配的档案。精简档和本机模型使用较短的同源规范；自定义角色和关闭内置人格时不加载雪乃技能。统一高二主线与十四卷尾声高三／社团部长变化的时间表述，不凭现实日期推算角色年龄。
- 候选构建按具体源码提交分组，避免前一个候选的安装验证阻塞用户后续提交；发布权限仍仅限明确的测试版发布任务。
