# 全身逐帧桌宠 · 第一套完整动作包

本次交付采用真实绘制的逐帧 PNG。程序只切换图片，不进行骨骼模拟、整图旋转或网格变形。已接入主界面人物区，提供独立预览。

## 素材

`public/avatars/yukino-sprite/frames/`：24 张 384×512 RGBA PNG，每组 8 帧。已切分、按人物高度等比例缩放、居中和统一落脚位置，跨状态使用相同中立首尾帧。

- idle：安静待机与眨眼；约 4.88 秒一轮，闭眼约 95ms。
- talk：无声说话动作演示；不是音素同步。
- greet：点击后的抬手问候，结束返回待机。

`manifest.json` 给出帧顺序、各帧毫秒时长和循环规则。三份 `*-preview.gif` 可直接在 GitHub 查看。GIF 使用浅色底，程序使用带透明通道的 PNG。

画面基于用户提供角色参考及确认的动漫外观，由图像工具生成。生成帧之间仍有细微服装线条和发丝变化，属于第一版逐帧素材，不能等同于精修手绘动画。全部角色完整入框；背景透明；未声称完成 Live2D 绑定。

## 使用

- 项目：`npm install` 后 `npm run dev`，主界面人物区自动加载；点击角色打招呼，“说话演示”切换到口型动画。
- 独立页：开发服务器 `/sprite-preview.html`，也随 `npm run build` 复制到 dist。
- 只预览素材：`python -m http.server 8765 --directory public`，访问 `http://127.0.0.1:8765/sprite-preview.html`。
- EXE：按项目现有 Windows 构建方式 `npm run dist:win`。本次未发布 Windows 安装包，也未验证 Windows 实机。

资源全部本地加载，没有额外模型服务。暂停和减少动态效果受支持，隐藏页面后停止推进帧时间。文字生成只显示“思考”提示，不冒充语音播放。

## 素材处理

`scripts/prepare-sprite.py idle.png talk.png greet.png` 可从三张 4×2 原始图集切分并生成这些资源；依赖 Pillow。仅裁切、等比缩放、透明合成和编码，不生成中间动作。
