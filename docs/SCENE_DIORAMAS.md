## 操作

主界面和观赏界面都有小菜单，按室内／室外选择。选择场景启用背景延伸并关闭壁纸显示，但不删除用户导入的壁纸和配置。

Ctrl＋滚轮渐进缩小至能看完整场景的轻俯视微缩景致；Ctrl＋拖动水平环视，水平滚轮或 Ctrl＋Shift＋滚轮也可环视。松开 Ctrl 缓慢回到原视角，不保存临时镜头。小菜单的按住总览按钮支持指针和键盘。

## 切换与性能边界

`src/scenes/registry.mjs` 延迟加载工厂，共用项目 Three。宿主 `environment-backdrop.mjs` 只拥有一个长期 renderer；在构造候选前同步冻结旧帧并让浏览器有绘制机会，暂停共享 renderer 的旧场景绘制，编译并完成离屏真实首帧后才提交。失败保留旧场景；过期请求不提交；成功后执行约 1.65 秒模糊扩散。

DPR、阴影和刷新频率有上限；窗口隐藏停止场景 RAF。同步几何构造仍可能造成短暂 CPU 停顿，林间场景较重，不能把功能测试当作全硬件性能验收。便利店／书店原独立后处理 composer、林间全屏 shader 背景未完整移植；不能声称与原 HTML 逐像素一致。

旧几何工具保留用于历史回归，不再由场景宿主或人物 renderer 加载。源 HTML 与参考图片保持原位，不提交需求图片。
