## 构建与验证

`npm run prepare:companions` 校验三张原版精灵图片，并下载、SHA-256 校验原仓库 80,380,288 字节音频包，安全解压 2391 条音频；构建阶段需要 Python 3，用户播放内置预录语音不需要 Python。文件名、条目数、单文件大小、解压总量均受限制。音频通过 `electron/**/*` 直接随应用打包，压缩包与生成文件不进入 Git。

归档 SHA-256：`7b8b150e6b2593b43dd44bf476348b7a44ea0ab6c90d9bddc6a31cce1e2cb6bc`。资源出处见 `electron/companion-view/assets/provenance.json` 与 `electron/companion-view/THIRD-PARTY-NOTICES.txt`。

自动验证：`node --test tests/companions.test.cjs tests/pet-features.test.cjs` 覆盖旧设置导入、参数范围、持久化、语录冷却、专注完成/取消、窗口移动限制、主/子窗口 IPC 身份、关闭记忆与语音试听命令。

实际 Electron UI 检查：`npx electron scripts/capture-pet-ui.cjs --output build/pet-ui-review`，运行生产桌宠页面、生产 preload 和真实 IPC manager，仅使用临时设置。检查精灵绘制、完整菜单、最低缩放滚动、气泡/透明度、双击、专注、移动及 OGG 元数据解码；不会发 API 请求或播放语音。Linux 需显示服务器，Windows CI 可直接运行。输出截图与 `report.json`，截图成功后才可声称视觉验证通过。

## 明确边界

原版 WPF 程序没有嵌入新应用；保留其设置、资源和交互能力并迁移到现有 Electron 架构，动画/随机走动时机不承诺逐帧与 WPF 完全一致。角色位置与偏好跨启动保存，原版的临时情绪/亲密状态同样不作为用户个人记忆存储。3D 动作和换装仍等待模型资源接入。
