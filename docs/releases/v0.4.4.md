# Yukino Companion 0.4.4

## 更新内容

- 推理环境：随安装包补齐运行环境下载清单（runtime-catalog.json）、默认语音参考资源（voice-presets）与多连接下载器（aria2），修复 0.4.3 提示推理环境未准备且无法一键安装的问题。
- 账号：桌面端、安卓端登录注册及官网入口切换至正式域名 https://yukino.fqxxzyw.cn，旧版已保存配置自动迁移；注册时昵称可留空，系统给旧账号和新账号分配可修改的昵称，桌面和网页登录后显示昵称首字头像。
- 场景材质：赛璐璐模式对叶片、木材和石材分别按受光分层，玻璃和水面使用原有反射。
- 场景切换：同一地点切换常规和赛璐璐时画面短暂交叠，保留当前视角。更换地点仍从人物脚下向外展开并逐渐清晰。
- 自定义角色：登录后，新建角色会备份名字和文字设定。角色管理页可重新备份并恢复本机缺少的角色。GLB 模型和 API Key 仅保存在本机。
- 更新体验：发现新版本时可在下载前查看分类更新内容，下载中可取消或重试，下载后可稍后安装。
- 兼容性：Windows 安装版优先复用旧安装器区块。缺少缓存、区块表损坏或服务器不支持 Range 时，界面会切换为完整安装包。便携版手动保存完整安装包。
- 稳定性：启动安装器前再次核对安装包大小和 SHA-512，并等待应用状态保存。更新过程中保留本地模型及用户文件。

## 安装与校验

Windows x64 用户可下载 Base-Setup.exe 或 Portable.exe。两者均未做 Authenticode 代码签名。可用本页 SHA256SUMS-0.4.4.txt 核对下载文件。

0.4.1 / 0.4.2 升级到 0.4.3 需要全量下载一次。0.4.3 向后续版本升级时优先差分下载。此次发布的分类更新说明功能由 0.4.4 客户端提供，安装后在下次有新版本时显示。
