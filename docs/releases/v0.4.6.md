# Yukino Companion 0.4.6

> 发布日期：2026-11-26 · [GitHub Release](https://github.com/fqxxzyw/Yukino-Companion/releases/tag/v0.4.6) · [官网下载](https://yukino.fqxxzyw.cn/#download)

## 更新内容

- 推理环境：修复部分 AMD（锐龙 1000–5000 等无 AVX-512）及较老 CPU 选择「CPU 通用环境」时 `import llama_cpp` 报 `0xc000001d`（`STATUS_ILLEGAL_INSTRUCTION`）导致无法启动本地推理的问题。
- 推理环境：安装包内置 AVX2 版与通用兼容版（无 AVX/AVX2/AVX-512）`llama-cpp-python==0.3.36` wheel；自检命中非法指令时优先离线修复，未知电脑无需联网即可完成第一次修复。
- 推理环境：内置 wheel 不可用时自动回退 Cloudflare R2（`dl.yukino.fqxxzyw.cn/wheels/cpu/...`），AVX2 路线再加 `abetlen.github.io` 官方源；全部失败才提示 CPU 过旧，并显示中文错误而不是 Python 堆栈。
- 推理环境：CUDA 环境若因同一指令集问题无法加载 `llama_cpp`，自动降级为 CPU 兼容 wheel 保证应用可运行（该次运行不再启用 GPU 卸载）。
- 推理环境：CPU 运行时构建默认 `GGML_NATIVE=OFF`、`GGML_AVX512=OFF`、`GGML_AVX2=ON`，避免再次生成依赖 AVX-512 的运行时。
- 镜像源：PyTorch CUDA 12.4 新增上海交大 PyTorch + 清华 PyPI 路线；CUDA 与 CPU 轮子继续优先使用自有 R2 镜像，GitHub 作为官方后备。
- 下载与更新：共享资源下载、CUDA/CPU 轮子与应用内增量更新继续优先走 Cloudflare R2，GitHub Release 保留为正式归档与自动回退。
- 稳定性：补充 CPU 非法指令、内置 wheel 离线修复与 CUDA 降级路径的单元测试；源码包下载支持 PyPI 官方 sdist 的固定哈希回退。
