# Yukino Companion 0.4.1

> 发布日期：2026-11-18 · [GitHub Release](https://github.com/fqxxzyw/Yukino-Companion/releases/tag/v0.4.1)

## 更新内容

- Live2D：完整 Live2D 雪乃随包发布，安装版和便携版直接读取 `resources/live2d`。
- 3D 服装：黑色旗袍修正版移除 `Spring_01_skirt` 的运行时蒙皮绑定，恢复连续腰线；头部骨骼下移少量，脖子接合更紧。
- 界面与登录页：登录页壁纸改为左侧裁切，人物完整显示；登录时不再露出背景场景按钮。
- 桌面默认配置：默认关闭主窗口后保留桌面 3D 人物，人物默认使用原始材质。
- 服装与场景：服装卡片只保留缩略图、简短名称和选中勾；场景菜单新增「环境跟随时间」。
- 渲染细节：赛璐璐轮廓按屏幕宽度 40% / 20% / 40%，透明发片使用原 alpha 贴图裁切。
