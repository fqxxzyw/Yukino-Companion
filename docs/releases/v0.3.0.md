# Yukino Companion v0.3.0 · 玻璃界面与双语桌面陪伴

本版提供 **Windows x64 CPU 完整离线翻译包**，包含玻璃质感界面、专属图标、中日双语对话与桌面陪伴。Hy-MT2 翻译模型和 CPU 运行库随安装包提供，安装后无需另装 Python 或下载翻译权重。请从本次 Release 的 Assets 下载安装包。

## 主要变化

### 更清晰的玻璃质感界面

- 浅蓝与蓝色默认主题，一体化无边框标题区、圆角玻璃面板、柔和背景层次和统一设置控件。
- 提高正文、辅助文字、输入提示与按钮的可读性；自定义强调色和背景色时调整文字对比度。
- 保留侧边栏展开/收起、人物区域左右布局和隐藏、减少动态效果。
- 新增专属应用图标，并用于安装器、快捷方式和应用窗口相关资源。

### 中日双语与本地翻译

- API 可以同时返回中文与日文；日文缺失或无效时自动尝试本地补译。
- 可选择 API 仅返回中文、全部由本地模型译成日语。
- 气泡支持中文、日本語、双语；既可全局设置，也可逐条切换。
- 历史消息可单独补译，或翻译后朗读；翻译失败保留中文与错误提示。
- 内嵌官方 Hy-MT2-1.8B 的 Q4_K_M GGUF，模型约 1.13 GB，固定版本与 SHA-256 校验。翻译模型及其 CPU 运行库随完整包提供，安装后不必再下载翻译模型或另装 Python。

该模型是翻译组件，不是训练完成的雪乃性格 LoRA。对话生成仍使用用户配置的远程 API 或已经运行的本机兼容服务。

### 日语语音衔接与音色选择

- GPT-SoVITS 合成语言固定为日语，气泡显示中文也不会改变朗读语言。
- 日文准备完成后进入语音分句队列，过滤常见思考标签、代码和链接后顺序合成、播放。
- 支持自动朗读、日语试听、历史消息朗读、停止、音量与卸载；取消后丢弃迟到的翻译和音频。
- 已登记用户 Release 中 GPT e1–e5 与 SoVITS e1，支持下载、校验与选择。训练轮次不作为音质排名。
- 保留用户自行选择 GPT `.ckpt`、SoVITS `.pth`、模型版本与参考语料的功能。

**语音仍需要用户提供 3–10 秒参考音频和准确转录。** 参考音频语言应按其实际内容设置，与回答固定日语合成分开。当前音色 Release 未包含参考音频，不能仅凭两种权重就完成出声验收。BERT/HuBERT、所选音色通过声音设置另行准备；它们不因翻译包完整就自动齐备。

### 桌宠、关闭行为和陪伴时间

- 接入指定 `yukino_desktop_pet` 仓库的真实逐帧素材，通过 Electron 透明窗口提供基础动作、拖动、缩放、置顶和双语气泡。
- 关闭主窗口时可完全退出、只留 Q 版桌宠、只留人物模型位置，或同时保留两者；也可保存关闭偏好。
- 留下形象时应用继续在托盘运行，可从托盘重新打开对话或完全退出。
- 记录累计、今日、本次使用时间和独立桌面陪伴时间；两个形象同时开启不重复计时。
- 锁屏、休眠以及没有可见窗口时暂停；跨日按本机日期拆分，本地原子保存。

**人物模型窗口当前仍为明确的 3D 占位。** 正式 3D/Live2D 形象、动作、换装和口型还未完成。本次桌宠适配也没有移植原独立程序的全部语录、预录音频、专注计时和开机启动功能。

### 保留完整人物规范

保留个人资料、性格、兴趣、能力、家庭关系、经历及完整行为指导与情境示例。详细/精简只调整运行提示长度，不拆成前、中、后期人格。每次 API 请求继续由主进程组装人物规范、追加设定与启用的手动记忆。

## 安装包范围

安装包为 `Yukino-Companion-0.3.0-Setup.exe`，具体大小见 Assets。附件同时提供 `SHA256SUMS.txt` 与资源记录。GitHub 自动生成的 Source code 压缩包不含可直接安装的软件或大模型权重。

| 组件 | 本轮 CPU 完整包范围 |
| --- | --- |
| 桌面应用 | Electron、玻璃质感 UI、专属图标、角色规范、桌宠素材 |
| 本地翻译 | Hy-MT2 Q4_K_M 权重、CPU 翻译运行库、worker、模型清单与许可 |
| 语音运行环境 | Python、GPT-SoVITS 推理代码、CPU 推理依赖、FFmpeg 与相关运行资源 |
| 语音基础模型与音色 | 软件提供固定资源下载/校验和本机文件选择，按声音设置准备 |
| 参考音频和转录 | 用户自行提供，不随本轮音色 Release 提供 |
| 角色 LLM / 性格 LoRA | 不作为本轮已训练完成的模型发布 |
| 3D 模型与动作 | 保留接口和明确占位，等待后续素材 |

CPU 包面向无需独立显卡的 Windows x64 使用场景。GPU 用户可以选择自行准备的外部兼容 CUDA 环境；**本轮没有已验证的 CUDA 发行包，也不宣称完成 GPU 实机测试**。翻译与语音分别使用各自的运行库和设备状态。

安装器尚未使用代码签名证书；更新应用图标和版本资源不等于证书签名。

## 开始使用

1. 从 Releases 的实际 Assets 下载安装包并安装。
2. 在「对话 API」填写兼容地址、模型 ID 和密钥，保存并测试连接。本机免鉴权服务可留空密钥。
3. 在「双语与翻译」选择双语生成方式和默认气泡语言；CPU 完整包中的本地翻译可使用内嵌资源。
4. 需要声音时，在「声音与语音」准备公共模型、选择音色，提供参考音频与准确转录，加载后试听日语。
5. 在「形象与展示」选择桌宠或模型位置、气泡语言和关闭策略。托盘可找回主窗或彻底退出。

原有会话、人设和手动记忆继续使用本机数据目录。旧消息没有日文时先显示中文，可按需补译；不会因升级就自动把全部历史发送给外部服务。API 密钥由系统安全存储加密，跨设备迁移可能需要重新配置。

## 验证状态与已知限制

- 源码检查记录为 Node 88 项、Python 14 项通过，覆盖双语衔接、人格注入、取消、资源校验、计时和关闭策略。对应发行提交的结果见本次 Actions 验证记录。
- Linux CPU 已运行真实 Hy-MT2 翻译：15 个样例，以及中文到真实翻译、日语分句、最终语音输入检查的链路。记录见[翻译样例](https://github.com/fqxxzyw/Yukino-Companion/blob/main/docs/reports/translation-cpu-smoke-20261025.json)。
- 样例仍有个别错词，人物语气与中日语义一致性需要进一步复核；这不是正式翻译质量基准。
- Windows 构建、安装包资源、Electron 截图和发布后翻译结果见本次 Actions 验证记录。托盘交互、透明窗口、DPI、多屏及手动安装仍需实机验收。
- 当前缺用户参考音频与准确转录，没有完成用户音色的真实合成、播放和音质验收。前述文本链路验证没有生成音频。
- 桌面截图识别、麦克风输入、语音识别、自动记忆、正式 3D/Live2D 与公共社区投稿/同步仍未接入。
- 新性格 LoRA 尚未完成整轮训练。角色模型完成并验收后会作为独立 Release 附件，与桌面安装包分开。
