# Yukino Companion 0.4.0 · 本地对话与完整桌宠

本版采用 **小型 EXE 安装器 + 完整应用分卷 + 独立共享推理环境**。EXE 本身不含数 GB 权重；本地对话、翻译、默认音色和桌宠资源全部位于应用分卷，安装后保存在本机。

发布流程按需求先上传 EXE，再上传全部分卷，随即供用户测试，耗时自动检查在独立任务继续；CUDA 编译不阻塞 EXE 发布。**请以本页末尾工作流写入的验证状态为准；附件出现不代表测试通过。** 新资产上传期间，安装器可能暂时找不到尚未完成上传的分卷。

## 安装

1. 下载 `Yukino-Companion-0.4.0-Setup.exe`。联网安装时，安装器会从同一 Release 下载缺少的应用分卷，显示下载进度，允许取消。
2. 如需离线安装主应用，同时下载所有 `Yukino-Companion-0.4.0-windows-x64.zip.partNNN`，与 EXE 放在同一文件夹，运行 EXE。无需手动解压分卷；不得漏卷或改名。
3. 安装器校验每卷和组合 ZIP 的 SHA-256 后再解压。它拒绝包含其他文件的安装目录，并保留用户数据；取消或失败不会用残缺应用覆盖旧安装。
4. 首次打开软件可选择安装共享 Python 推理环境，也可跳过并使用远程 API 文字对话。环境包含 Python、PyTorch、llama-cpp-python、GPT-SoVITS 代码等公共组件；**下载的是公共运行环境，不是再次下载已内置的对话或翻译权重**。
5. 语音还需要公共 BERT/HuBERT 资源，首次引导可下载。默认 GPT/SoVITS 音色和日语参考 WAV 已随主应用安装。资源齐备后，本地对话、翻译与合成无需远程 API。

当前测试包提供 CPU 环境下载，NVIDIA 用户也先使用 CPU。CUDA 12.4 环境独立构建，待检查通过后随后续应用更新提供；设置会明确提示未发布，不能把自动选择 CPU 写成已使用 GPU。自行配置的兼容 GPU 环境仍可按实际加载结果使用。

`Yukino-Runtime-...cpu...partNNN` 是引导使用的独立公共环境分卷，通常无需手工处理。Python、PyTorch、CUDA 等环境文件不内嵌主应用。当前应用离线安装与“全套推理环境已离线安装”是两件事；无网络电脑应提前通过另一台机器准备兼容环境，或在设置中配置已有 Python。

## 本版变化

- 内置实际训练产物的 Qwen2.5-1.5B 角色 GGUF，选择本地对话即可由应用管理加载与回复，不需另开 HTTP 服务。支持 CPU/GPU 检测、停止、错误提示与 CPU 回退。
- 保留 Hy-MT2-1.8B Q4_K_M 翻译模型，API 或本地回答统一进入中文／日语处理与语音队列；合成语言固定日语。
- 内置 GPT e2、SoVITS e1 与 3.083 秒日语参考 WAV；仍可自行导入训练好的权重、选择其他轮次、参考语音和文本。参考文本有两次自动转写记录，不能等同于人工听校。
- 保留完整角色资料和行为规则，修正普通聊天主动解释“数字角色”“在原著里”的优先级；明确询问 AI、软件或实际能力时仍如实回答。
- API 提供供应商预设与模型下拉框，可获取账号有权访问的模型，保留自定义兼容地址。
- 完整桌宠设置、2,391 段预录语音、语录、专注计时、置顶、拖动、透明度、开机启动等按桌面环境实现；桌宠菜单使用独立样式。
- 优化文字对比度、人物区域调整与双语显示，首次配置可安装、跳过、查看组件状态。保留人物模型／桌宠／两者的关闭策略及陪伴时长。

3D/Live2D、动作、换装、口型和桌面视觉仍未完成，不将预留窗口算作正式模型。

## 模型与校验附件

- `Yukino-Local-1.5B-Persona-0.4.0.zip`：与主包一致的独立 GGUF、清单、基础许可及训练信息。
- 训练 LoRA ZIP：真实训练适配器与报告，按实际已上传附件另行提供，不含私人小说索引。
- `app-payload.json`、`runtime-catalog.json`：逐卷大小、SHA-256、组合包哈希和下载地址。
- `SHA256SUMS.txt`、`release-assets.json`：主安装器、主应用分卷及清单校验。

训练完成与角色质量达标不同。模型的训练步数、基础模型 revision、适配器哈希、损失和开发／保留测试输出，以随附报告为准；不会用未训练的基础模型冒充完成的人格产物。

## 验证范围

工作流在上传后执行 Node/Python 测试、真实 Electron 主界面及桌宠截图、从分卷安装及再次校验、发行运行环境 CPU 中日翻译、默认音色真实日语合成。实际输出及报告上传到 Release/Actions。

语音检查确认真实加载、有效非静音 PCM，不能证明主观音质或每个读音正确。界面自动截图不替代所有 Windows DPI、多屏、托盘和 GPU 实机测试。当前文档不会提前宣称这些检查通过；状态由该次运行填写。

当前本地 30 条真实回复检查已发现同班关系、虚构分手、无图片却声称收到图片等错误。普通自我介绍不再主动声明数字角色，但不能据此认为人物知识与行为完全通过验收。完整原始输出见模型评估报告。
