# 安装版与便携版更新

安装版在启动 5 秒后检查本项目 GitHub 最新正式版，随后每 6 小时检查一次。也可以在主窗口打开「应用更新」手动检查。下载时显示变化部分或完整安装包、实际传输字节和进度。可以取消下载、稍后再装，或在下载校验通过后选择「重启并安装」。

0.4.1 / 0.4.2 升级到 0.4.3 需要完整安装包。0.4.3 及以后优先复用旧安装器。缓存位于 %LOCALAPPDATA%\yukino-companion-updater。缺少缓存、块图损坏、服务器不支持 Range 或重建失败时会改为完整下载。下载的安装器必须通过 latest.yml 的 SHA-512 与长度核验。

便携版提供保存完整安装包和打开 GitHub 两个入口。保存后关闭应用，手动运行下载的文件。

构建与发布见 [Release 资产和验证规范](RELEASE_UPDATE_SPEC.md)。
