# 安装版与便携版更新

## 安装版（推荐）

- 启动 5 秒后自动检查最新正式版，随后每 6 小时检查一次；也可以在主窗口点击「应用更新」手动检查。
- 发现新版本后，下载前会展示版本号和分类更新内容。下载过程中显示「变化部分」或「完整安装包」、已传输字节与进度，支持随时取消或重试；下载校验完成后，只有点击「重启并安装」才会保存状态并静默完成更新，保留本地模型与用户数据。
- **小增量更新演进**：
  - `0.4.1 / 0.4.2 → 0.4.3+`：首次升级需下载完整包建立缓存。
  - `0.4.3 / 0.4.4 → 0.4.5`：一次性完成小增量目录结构迁移（差分下载约 177–184 MiB，节省约 40%）。
  - **`0.4.5` 及以后**：已启用 `store-asar` 与静态素材拆包，后续纯代码更新仅需下载约 **0.5–1 MB** 变化区块；新增或调整单个 3D 模型时也只下载变动部分。
- **双源加速与校验**：下载优先通过国内高速节点 `https://dl.yukino.fqxxzyw.cn`（Cloudflare R2），异常时自动回退至 GitHub Releases。缓存位于 `%LOCALAPPDATA%\yukino-companion-updater`，缺少缓存、块图损坏或服务器不支持 Range 时自动改为完整下载；所有安装文件必须通过 `latest.yml` 的长度与 SHA-512 核验后才会执行。

## 便携版

便携版无法原地覆盖自身，应用内提供「保存完整安装包」和「前往 GitHub」两个入口。保存完整包后请关闭当前程序，再手动运行已下载的安装包（或在官网 <https://yukino.fqxxzyw.cn/#download> 直接下载最新便携版）。

构建、R2 同步与发布验收规范见 [Release 资产和验证规范](RELEASE_UPDATE_SPEC.md)。
