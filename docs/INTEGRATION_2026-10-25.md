# v0.3.0 双语、语音与桌面陪伴集成记录

日期：2026-10-25。此文记录本轮源码功能和验证边界。用户随后已授权恢复打包并发布新 Release，当前准备 Windows x64 CPU 完整离线翻译包；Windows CI 结果待完成。前期暂停仅是当时的工作状态，不再限制本轮发行。

## 本轮结果

- 统一已有完整角色规范与 GPT-SoVITS 推理代码，保留人物全文、详细/精简运行卡、手动记忆和多 API 配置。
- 对话保留中文与日文两份正文；气泡可全局或逐条显示中文、日文、双语。旧消息可仅补译，或补译后朗读。
- 本地翻译采用官方 `tencent/Hy-MT2-1.8B-GGUF` 的 `Q4_K_M` 文件，约 1.13 GB；通过独立 JSONL worker 调用固定版本 `llama-cpp-python`，不使用角色 LoRA 执行翻译。
- 合成语言固定日语；参考音频语言独立设置。GPT e1–e5 与 SoVITS e1 下载目录已接入，保留本机自选训练文件、模型版本与参考语料。
- 接入指定桌宠仓库的逐帧素材、独立透明窗口、关闭策略、托盘与本地使用/陪伴时长。模型专窗保留明确的 3D 占位，真实模型、动作和口型仍待用户素材。
- UI 改为一体化浅蓝玻璃面板、系统字体、圆角和柔和背景层次，提高正文与辅助文字对比度，并保留颜色自定义。加入专属应用、安装器和快捷方式图标。

## 对话到声音的顺序

1. 主进程从已保存设置构建角色提示和启用的记忆，移除客户端传入的旧/伪造 system 消息。
2. API 双语模式要求返回 `{"zh":"中文正文","ja":"日文正文"}`。中文字段解码后流式显示，原始 JSON 不进入气泡或语音队列。全部本地翻译模式只要求 API 返回中文。
3. 取得完整回答后，使用 API 的有效日文或调用本地模型补译。本项目自有 `oregairu-small` 服务自动采用中文加本地翻译，以减少对小型角色模型的格式要求。
4. 保存中文、日文和翻译结果状态，并向桌面气泡同步同一份双语回答。
5. 自动朗读开启时，只把完成的日文送入语音文本过滤与日语分句队列，再依次合成和播放。翻译失败保留中文与错误，日文字段为空，不朗读中文回退。
6. 停止、切换会话或开始新任务会取消旧朗读；历史消息补译通过独立请求 ID 取消。即使旧翻译/音频迟到，也不能覆盖新任务或继续播放。

日文脚本检查只是防止明显错误回退的边界，不等于正式语种鉴定或中日语义等价验证。纯汉字等片段由日语分句合并逻辑处理；无法安全合并时明确报告，不能静默截断或当成中文合成。

## 关键接口

接口仅向主窗口的可信主 frame 开放；桌宠窗口使用单独的最小权限 preload。

| renderer 接口 | 用途/返回 |
| --- | --- |
| `send({id,profileId,messages})` | 返回 `{ok,bilingual:{zh,ja,translationStatus,translationError?,source}}`；取消返回 `{stopped:true}` |
| `onChunk(callback)` | 接收当前请求 `{id,text}` 的中文片段；不直接触发 TTS |
| `translate({text,source:'zh',target:'ja',requestId})` | 本地补译，返回日文 `text` 与模型/设备元数据 |
| `translationStatus/Save/Install` | 检查资源、保存环境与设备设置、安装并校验固定模型 |
| `translationCancel(requestId)` | 取消对应补译；带 ID 时不误杀其他排队任务 |
| `voiceInstall('core'\|'yukino-e1'…'yukino-e5')` | 下载并校验公共基础模型或所选音色；返回相应资源路径 |
| `voiceSave/Probe/Load/Unload` | 保存语音配置、检测设备、加载/卸载权重与参考音频 |
| `voiceBegin/Synthesize/Stop` | 绑定朗读会话 ID、合成日语片段、停止本应用拥有的任务 |
| `companionState/Set` | 读取或修改显示模式、关闭行为、气泡语言、位置、缩放和时长 |
| `closeChoice('quit'\|'model'\|'pet'\|'both')` | 完全退出，或隐藏主窗并留下所选形象 |
| `onCloseRequested` | 系统关窗和界面关闭按钮共用选择流程 |
| `onFlushState/flushComplete` | 完全退出前刷新 renderer 尚未落盘的状态，再等待主进程保存与清理 |

存档消息使用 `content` 保留中文兼容字段，并添加 `zh`、`ja`、`translationStatus`、`translationError`；发送后续聊天上下文使用中文，不重复把两份译文全部发给 API。气泡偏好不改变音色或参考音频语言。

## 本地翻译资源

固定模型清单：[translation/model-manifest.json](../translation/model-manifest.json)。当前模型 revision 为 `a0c709d9fac510f2c807aa3af52872340dc37a4a`；文件 `Hy-MT2-1.8B-Q4_K_M.gguf` 为 1,133,080,448 字节，SHA-256 为 `dc5f44fcf1fa496ee7ad725982c0c8c553a4de00259b53af84c4b89fb0c06699`。保留官方 Apache-2.0 许可与来源信息。

模型安装先验证大小和哈希，再原子发布；会话过程中不会自动安装依赖。已准备权重可离线加载。运行库固定为 `llama-cpp-python 0.3.36`，CPU 采用校验后的官方 wheel；CUDA 采用固定源码构建。本轮 CPU 安装规则包含翻译 worker、完整模型、许可和运行库，安装后中译日无需另外下载模型或安装 Python；实际安装内容待 Windows CI 检查。

CPU 路径已真测，本轮发布 CPU 通用包。设置仍允许 GPU 用户选择外部兼容 CUDA 环境；本轮不发布或宣称已验证 CUDA 包。自动模式只在运行库和设备支持时尝试 GPU；运行库构建类型、实际 offload 与语音模块的 PyTorch CUDA 是分别处理的状态。干净 Windows 与 CUDA 环境仍需实机验证。具体命令、版本与设备说明见[TRANSLATION.md](TRANSLATION.md)。

## 音色资源与参考语料

资源来源为用户指定的 [v0.1.0-framework.1 Release](https://github.com/fqxxzyw/Yukino-Companion/releases/tag/v0.1.0-framework.1)。已登记 GPT e1–e5，以及压缩包中的 SoVITS e1，使用固定下载地址、精确大小和校验值。多个 GPT 轮次共用 SoVITS；轮次不是音质评分。

压缩包解压只接受清单中的预期成员，拒绝路径穿越、长度和哈希不符。手动导入仍接受本机 GPT `.ckpt` 和 SoVITS `.pth`，不会强迫用户使用内置预设。

该 Release 没有参考音频。真实合成需要 3–10 秒干净 WAV/FLAC、准确转录以及实际音频语言。当前不能声称已完成用户音色出声、音质或训练配对验收；也不能把结构可读取与真实推理成功混为一谈。详见[VOICE_INFERENCE.md](VOICE_INFERENCE.md)。

## 桌宠、模型占位与计时

指定源仓库为 [fqxxzyw/yukino_desktop_pet](https://github.com/fqxxzyw/yukino_desktop_pet)，固定提交 `70269cfc0a82756d7730425a38e53233bdf90aed`。使用三张约 3.5 MB 的逐帧 PNG，Electron 重新实现基础透明窗口和动作，不依赖原 WPF/.NET 程序。未移植 2391 条预录音频、全部情绪/语录规则、专注计时和开机启动，以免与统一日语合成叠音或宣称不存在的功能。

主窗关闭可选择完全退出、只留桌宠、只留人物模型位置或同时保留两者。留下形象意味着应用继续在托盘运行。模型位置明确标记 3D 模型和动作待接入，不能作为正式人物渲染验收。

`companions.json` 保存模式和位置；`companionship.json` 保存使用与陪伴统计。主窗或至少一个形象可见时计入使用时间，桌面形象可见时另计陪伴时间；两个形象不重复累加。锁屏/休眠暂停，跨日按本机时间拆分，单调时钟避免改系统时间膨胀统计。没有窗口可见时仅驻留托盘不计时。损坏记录保留并提示，不静默覆盖。

详见[DESKTOP_COMPANIONS.md](DESKTOP_COMPANIONS.md)。
