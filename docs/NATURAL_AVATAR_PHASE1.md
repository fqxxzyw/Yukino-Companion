# 自然陪伴形象：第一阶段交付

目标：全身动漫形象，安静、克制，连续自然的微动作。

## 已交付
- 独立于渲染器的 NaturalMotion 参数生成器：不等间隔眨眼、平滑视线、轻微呼吸与摆动、口型音量包络。
- 暂停、页面隐藏恢复、减少动态效果支持的独立预览页。
- 三项自动测试：十分钟参数稳定性、停止说话与减少动态效果、不同帧率与长帧处理。

## 运行
在仓库目录安装原项目依赖后运行 `npm run dev`，访问终端地址下的 `/avatar-preview.html`。选择前面生成的全身 PNG，图片只在本机读取。移动鼠标、调整状态和音量，观察动作和参数。

预览入口仅用于开发服务器，当前默认 Vite 生产构建不包含此独立页面；未接入 EXE 主界面。测试：`node --test tests/natural-motion.test.cjs`，也包含在现有 `npm test` 中。

## 边界
这是立绘整体变换预览与动作控制代码，不是 Live2D 成品。当前未包含分层 PSD、moc3、model3.json、Cubism SDK 或真实语音。眼睛、嘴巴、头部和发丝参数显示在调试区，不能使一张扁平 PNG 独立变形。思考状态暂与待机共用动作。没有声称完成 Windows 实机或真实模型验收。

## 下一阶段素材与绑定
以已确认的全身动漫立绘为外观方向。须先清理背景，校正正面中立姿势，再拆分前后发、脸底、双眉、双眼（眼白/虹膜/上下眼皮）、嘴部（上下唇/口腔）、颈、躯干、双臂、裙、双腿；补齐遮挡区域。对齐复合结果应与定稿一致。

Cubism 中完成网格、变形器、转头与眨眼口型关键形态、发丝物理及导出后，才能实现真实 Live2D。模型适配器可将本控制器 headX/headY 映射到头部角度，gazeX/gazeY 映射眼球，eyeOpen 映射双眼开合，mouthOpen 映射嘴开合，breath 映射呼吸。实际参数 ID、范围及可用性必须根据导出模型核验；发丝优先交给模型物理系统，避免双重驱动。

每帧以秒调用 step；语音播放期间 setState('speaking') 并传入归一化音量。停止、取消、播放完毕必须 setState('idle')，等待平滑闭嘴。文字生成阶段不等于语音正在播放。
