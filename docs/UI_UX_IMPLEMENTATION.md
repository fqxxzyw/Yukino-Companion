### 本次收敛后的导航

- **常规**：本机资料、陪伴记录、使用帮助；不再堆放能力检查和重复快捷入口。
- **角色管理**：管理与新建 / 角色性格。新建时可按姓名复制中文提示词给外部 AI，检查结果后手动填写可编辑设定；没有自动 API 生成人设或导入。
- **聊天与陪伴**：聊天来源、主动聊天、勿扰与日常陪伴；不再混放 API、翻译和记忆。
- **模型与 API**、**双语与翻译**、**个人记忆**：各自独立侧栏入口，直接进入自己的页面，不必经过聊天分组。
- **语音输入**：独立的麦克风、录音方式、转写设置与测试页面。
- **语音输出**：朗读与试听 / 音色与参考声音；不再包含输入设置，环境诊断单独进入高级页。
- **人物与桌面**：聊天中人物显示、位置、宽度 / 桌宠陪伴 / 陪伴进度；不与新建角色混在一起。
- **高级与资源**：本地模型与资源、语音环境与诊断、导入人物模型、能力检查。
- 外观与视觉直接进入各自页面。高级子页提供「返回高级与资源」，页头只保留一个「返回对话」。

### 用户截图后追加的实际改动

- **缺资源提示**：设置顶部加入可暂时关闭的小提示框及叉号；只依据桌面版全部六项托管资源的真实检查判断缺失、等待环境或错误。资源齐全则不显示；浏览器没有 IPC 时明确无法检查，不伪造缺失或就绪。
- **一键部署全部**：预选本地聊天、翻译、语音合成、桌宠预录声音并打开现有 `SetupWizard`；只有用户再点「安装所选资源」才开始准备。已有完整资源按原流程复用，进行中的任务显示「查看部署进度」。本轮没有自动下载模型 / CUDA。
- **只读检查隔离**：新增 `setupStatus({scope:'all'})`，不修改向导的功能选择、错误或进行中的任务；保留 `features:[]` 的 API-only 语义。通知按事件合并检查、无定时轮询，同一观察器不并发检查，隐藏提示 / 卸载后清理订阅和定时器。
- **角色提示词**：沿用姓名验证、创建载荷与防重保护；剪贴板写入完成才提示成功，失败提供可选中的文本，不声称外部 AI 已生成内容。
- **拖动与吸附**：用户随后反馈人物不跟手、松开后文字闪移。代码确认旧拖动最多只允许工作区半宽，并且只给人物做 FLIP，聊天直接切换列。现在按带内边距的完整可用区域约束拖动，指针移动直接写位置变量，只在跨停靠区时更新提示；去掉主区列宽 CSS 过渡，松开时在同一 layout effect 为人物和聊天一起做 FLIP，聊天不作弹性缩放落点。用户确认该版本动作顺滑后，按最新反馈去掉顶部可见的「拖动」二字，保留图标、可访问名称及拖动能力；恢复背景 / 聊天在拖动期间 320ms 渐模糊、松开后 500ms 渐清晰，不再淡出文字。滤镜与 FLIP 分工独立，不恢复列宽过渡。保留 720ms 停靠缓冲、连续拖动 rebase、pointer cancel / lost capture / 失焦 / 隐藏取消、次要触点保护及 reduced-motion / reduced-transparency / forced-colors 降级；未移动的矩形不启动装饰动画。模型画布内仍拖动旋转。新增滤镜效果尚未截图复验。
- **提示词与业务边界**：用户指出提示词偏少。本轮仍以 UI 和实际交互修复为主；外部 AI 提示词目前是辅助起草版，不把复制入口当成完整角色生成、记忆管理或推理业务已完善。后续需补充角色提示词内容与业务验证；下载去重 / 句子合成并发 / 音色分类 / 环境适配仍按后续顺序逐项做。
- **轻透底色**：设置主体、导航和页头分层透出背景颜色，适度模糊，不称为真实光学折射；减少透明度模式恢复实底，高对比度模式使用系统颜色。实际背景、可读性和 DPI 仍待截图验证。
- 用户提供的 `Screenshot_20261031160742.png` 当时已确认是混乱旧 / 混合布局；端侧未更新的根因未定位，不能直接归因为缓存。用户随后真实确认 UI 设计通过和拖动顺滑，因此旧问题截图不再代表当前拒收状态；仍未取得本轮场景和渐模糊改动后的新验收截图。
