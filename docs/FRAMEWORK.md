## 双语、翻译与声音边界

默认要求 API 返回一个含 `zh`、`ja` 的 JSON 对象，主进程解码中文后发给界面，原始 JSON 不作为气泡正文或朗读文本。有效日文可以直接使用；缺失日文时由本地翻译补齐。全部本地翻译模式只让 API 生成中文，本项目自有 `oregairu-small` 服务也使用该模式。

存档保留中文与日文、翻译状态及错误。显示中文、日文或双语与合成语言彼此独立。只有已准备好的日文进入语音队列，中文不会成为翻译失败时的合成回退。旧消息可补译或补译后朗读；停止、切换会话和新任务会让旧翻译/音频失效。

GPT-SoVITS 的输出语言固定为日语，参考音频语言单独配置。保留 GPT `.ckpt`、SoVITS `.pth`、模型版本、参考音频及准确转录的自选入口。Release 音色目录列出 GPT e1–e5 和 SoVITS e1，不将“轮次更高”等同于“音质更好”。

本地翻译使用现成的 Hy-MT2 权重，与 Qwen 角色模型、性格 LoRA 和 GPT-SoVITS 音色是不同组件。完整应用资源包含模型权重，首次引导另行下载共享 Python/PyTorch/llama.cpp/GPT-SoVITS 环境，也可跳过。首批交付提供 CPU 环境，NVIDIA CUDA 12.4 环境后续提供；可安装选项以实际资源目录为准。CUDA 构建或导入检查不等于真实 GPU 推理验证。CPU 运行库不会仅因检测到物理显卡就获得 GPU 推理能力。

## 形象与关闭交互

主界面人物区域支持顶部拖动左右停靠、隐藏和边缘调整宽度，范围为 168–460 px，并受当前可用空间与聊天最小宽度约束。侧栏收起时，左侧人物随新的左边界移动；右侧人物维持右边界，聊天使用释放空间。

独立桌面模式提供 `none/model/pet/both`。关闭主窗默认询问，可保存“完全退出/只留模型位置/只留 Q 版桌宠/两者都留”的偏好。留下形象后应用仍在托盘运行；完全退出结束所有窗口与本应用持有的推理进程。模型窗口中清楚标明 3D 资源待接入。

真实桌宠素材从固定提交准备并校验，运行时无需远程加载形象。双语回复同步到桌面气泡，桌宠不会另开一个 API 请求。原项目的预录语音与互动规则已恢复，使用桌宠自身的语音开关和音量；对话日语合成仍通过统一 GPT-SoVITS 链路。

时长只在主窗可见或有陪伴窗口时统计；桌面陪伴时长另计。双窗口不重复，休眠/锁屏暂停，跨午夜按本机日期拆分，正常每 15 秒原子保存。详细数据和异常处理见[桌面陪伴说明](DESKTOP_COMPANIONS.md)。

## 数据与扩展

当前使用 `userData` 下原子 JSON；API 密钥通过系统 `safeStorage` 单独加密。SQLite 留待数据层扩展。私有对话、记忆、参考语料和统计不上传公共社区。

人物、语音和本地角色模型的扩展边界继续保留，见 `src/contracts.ts`。后续 3D/Live2D 渲染应接入现有窗口、消息与生命周期，不重新实现一套对话或语音状态。动作、表情、口型和换装只在真实资源支持时启用。

角色包保留完整人物档案与行为指导，所有阶段的性格维度作为同一个人格。性格 LoRA 已从旧知识适配器继续完成 186 条样本、1 个 epoch、47 步训练，并导出可实际离线生成的 Q4_K_M。仍存在事实、剧情和身份说明错误，训练完成不等于人格质量通过。计划将该模型放入完整应用资源，同时提供独立 GGUF 与 LoRA 附件；当前尚未完成 Release 交付。

EXE 和公共网站独立发布，未来可共享公开 GitHub 社区数据，包括同人作品和资源目录；本地私人数据与之分离。当前无社区登录、投稿、同步或可用私信后端。
