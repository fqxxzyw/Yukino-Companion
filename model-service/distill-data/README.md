# 雪乃纠错硬标签数据 v3

这是一组在本次任务中由 Codex 根据用户提供的小说与本地角色档案编写的**原创标准回答**。没有声称调用额外的教师模型 API，没有把模型输出自动标成真人验收，也没有把答案冒充小说原台词。`review_status` 是 `assistant-reviewed`，`human_reviewed` 为 `false`。

## 数据与任务

- `seeds.jsonl`：64 个独立场景族，每族 3 组问答，共 192 组；训练 48 族 / 144 组，验证 8 族 / 24 组，最终测试 8 族 / 24 组。
- `evidence.jsonl`：26 条来源记录，包含小说原文件 SHA-256、卷号、章节、EPUB 内文件名和短证据段落；角色风格、软件能力约束单独标明来源类型。
- `manifest.json`：样本数、划分说明及文件校验值。
- `author_corpus.py`：可重建以上数据的编写脚本。它只包含本次原创标签及来源定位，不会调用远程模型，不会自行训练。

内容覆盖父母与姐姐关系、错误前提纠正、姐妹年龄方向、亲昵称呼不等于血缘、家庭动机的解释限度、学年和社团职务的时间变化、叙述者猜测不等于事实、未知细节和伪造出处，以及克制、直接、具体而不过度训话的日常表达。多轮样本会要求模型纠正自己前一轮的错误；历史中的错误答案只应作为被遮罩的提示上下文，最后一条正确答案才是训练目标。

四个训练场景族标记为 `regression: true`，共 12 组：家人并非只剩姐姐、姐妹关系方向、老师与母亲不能混同、发现自己说错后明确更正。这些题已经用于训练，只能叫**训练内回归检查**，不能冒充未见过的评测题。

## 来源核验

关键纠错有直接原文依据：第 3 卷阳乃自称雪乃的姐姐；第 10 卷母亲出现并与姐妹见面；第 12 卷雪乃谈父亲的工作，同时提及姐姐和母亲。因此“阳乃是唯一在世亲人”或“独居说明父母不在”不符合所提供文本。

`source_type: user_supplied_epub` 的 `source_file` 是文件名，不包含本机私人目录。`paragraphs[].index` 为 `yuki_model.corpus.sections` 输出的零起始段落索引，`text` 是其规范化文本，不是原始 HTML 子串。核验应使用同一 EPUB 解析函数，在检查文件 SHA-256 后比较章节、成员路径和对应段落。不要直接在 HTML 字节中查找中文文本。

`source_type: local_character_pack` 的路径相对仓库根目录，记录了文件 SHA-256 和原文件中的定位字符串 `locator`。`kind` 区分 `style`、`product_policy`、`canon_pack_summary`、`evidence_scope`，不能把软件规则当成新的原作情节。摘要引用的底层小说线索可继续在 `characters/yukino/evidence.md` 查看。

## 划分与评估限制

同一个场景族的三个变体始终留在同一划分。验证和最终测试使用不同的任务形式与对话情境；**已知原作事实会跨划分出现**，因此这是熟悉事实上的新问法、推理和一致性测试，不是严格的未见知识测试。不要宣称它能证明所有小说知识都已被模型记住。测试集不得参与选检查点、学习率调整或提前停止。

事实纠正和角色风格需要分别检查。验证损失下降并不保证“不编家人关系”，关键词命中也不保证真正理解否定句。最终应人工比较完整回答，特别留意：否定范围、时间点、第三人称与第一人称是否合适、是否逃避已知事实、是否把朋友说成亲属、是否仍无根据地补完名字和动机。训练更多轮时应监测这些问题，而非只看训练损失。

## 重建

在仓库根目录运行：

```powershell
python model-service/distill-data/author_corpus.py 'D:/学习/春物资源/小说/春物中文版'
```

脚本读取本地 EPUB 并写入同目录 JSONL/JSON，不上传小说。云端训练使用随训练包保存的已核验数据即可；如要重新核验来源，应把同一批 EPUB 保存在云盘的资料目录中。
