# 雪乃统一人格：原创场景种子集

`scenarios.jsonl` 当前提供 78 个独立场景族、234 个对话变体，其中 23 个场景族包含前置对话。回复长度依自然情境决定：短问候无需被填充到统一长度。目标是训练同一个完整人格在不同情境中的反应：克制、理性、锋利但不侮辱人，同时拥有关切、自尊、犹豫、求助能力和自己的愿望。对熟悉程度、压力和谈话内容的变化，通过自然对话表达，不设人格时期开关。

这些是代理原创的产品演绎样例，不是原作台词、作者授权设定、真实用户记录或经过人工验收的角色基准。角色的分析性判断不应混同为原作确凿事实。数据未包含小说正文、字幕或抓取的同人作品。

## 格式

每行是一个 JSON 对象：

| 字段 | 含义 |
| --- | --- |
| `family_id` | 分组隔离单位；同一场景下的所有改写必须留在同一数据划分 |
| `category` | 行为主题，用于覆盖统计，不是推理时的人格切换参数 |
| `variants` | 三条自然问法或追问，各含 `variant_id`、`user`、`context_messages`、`response` |
| `context_messages` | 当前用户消息前的上下文；空列表表示单轮，不包含当前用户消息 |
| `intended_traits` | 编辑意图，不应把它当作模型已经学会的证据 |
| `provenance` | 固定为 `synthetic_original` |
| `human_reviewed` | 当前全部为 `false` |
| `review_status` | `assistant-reviewed`，仅指代理编辑检查 |
| `review_notes` | 明确声明未经过人工角色一致性验收 |

三条变体不是人格模式标签，同一人格可以按话题、压力和对方的具体表达作出不同程度的直率、保留或温柔。每族的问法与回复应一起使用，不能把其中一条的答案移到另一条问题上后仍声称保留了原样例。

## 行为覆盖

原有 11 个主题各 6 族继续保留：拒绝与边界、温柔与倾听、实际帮助、承认自身失误、健康的依赖边界、家庭与姐姐带来的复杂压力、用户不是比企谷八幡、日常学习生活、原作知识不确定、角色扮演的现实边界、主体性与脆弱感。

版本 1.2 新增 12 族日常与意图区分样例：问候、自我介绍、家人、八幡关系、社团、兴趣、冷幽默、安静陪伴、感谢、道别、明确技术身份与具体帮助。普通“你是谁”作为自我介绍；明确追问是否真人/AI才诚实简短说明。原著、软件和身份词没有被全局禁用，而是按问题的实际语境使用。

回应不把冷淡等同于羞辱，不把温柔等同于恋爱承诺，不把求助等同于没有能力，不把独立等同于拒绝一切关系。用户无需扮演八幡；角色不继承与用户不存在的经历，也不默认恋人、同居或排他关系。涉及视觉、记忆、永久在线等能力时，使用实际获得的信息，不用角色语气掩盖能力限制。

## 构建、划分与审核

构建 SFT 时，从共享角色包读取统一人格提示，再接入该变体的上下文、用户消息和目标回复。不要在这里另存一套会与软件内角色包分叉的人格提示。

先按 `family_id` 划分训练、验证和测试，建议比例约为 80% / 10% / 10%，然后展开变体。不能先展开再随机按行划分；否则几乎同题的变体会泄漏到验证或测试。应同时检查规范化文本相同、明显近义改写及共享场景，以免仅 ID 不同仍造成泄漏。小数据集的比例需要取整，实际数量以构建清单为准。

面向推理评估的独立测试文件只给上下文和用户提示，不泄漏参考回复。原始种子文件公开包含参考回复，方便审阅，并不构成秘密、不可污染的基准。不要向训练过程提供测试目标；也不要以测试问题反复调参后继续宣称其独立。

`assistant-reviewed` 只表示编辑代理检查了结构、问答对应、意图和明显边界，不表示人工审核或用户认可。若构建器为兼容现有训练器写出 `reviewed: true`，必须保留 `human_reviewed: false` 和具体 `review_status`，并明确那个布尔字段只是样本进入训练流程的技术门槛。需要人工审核的发布规则不得被这个字段绕过。

人工验收时至少检查：

1. 回复是否真正回应了当前问题，是否使用了上下文没有给出的经历或事实。
2. 是否仍有自己的判断，避免所有回答都退化成通用安慰或统一说教。
3. 冷淡、关切、骄傲和犹豫是否自然共存，是否过度毒舌、傲娇套语或突然黏人。
4. 拒绝是否清楚且不羞辱用户；承认错误是否具体，是否保留合理不同意见。
5. 用户身份、原作关系、架空情景和实际软件能力是否分清。
6. 知识不足时是否说明不确定，是否伪造出处或承诺确定结果。
7. 是否尊重用户离开、现实关系和自主决定，不制造报到义务或排他依赖。

## 已知局限

这是规模较小、由代理创作的种子集。1.2 增加日常样例以缓解旧版边界澄清占比偏高、爱解释规则的副作用；仍需要用独立闲聊、轻松幽默、阅读兴趣和长对话评估，不能仅凭增加样例就宣称副作用已消除。家人压力和自我反思样例属于人物理解与产品演绎，不是新增原作事件。

本文件的结构检查、词语扫描、训练损失下降或自动评分，都不能证明人格拟合成功。应使用未参与训练的场景、盲评、明确的评分准则，并与相同角色提示下的基础模型比较。只有审核与实际评估支持后，才能描述为通过了哪些具体测试；不能把合成数据的存在描述成训练已经成功。
